drishtipy

Lightweight Data Profiling & Data Quality for pandas

drishtipy is a lightweight, dependency-minimal pandas profiling toolkit for data quality, statistics, ML readiness, ETL analysis, PII detection, correlations, dataset comparison, and HTML reporting. It extends the native pandas workflow to catch schema errors, trace data quality metrics, and automate privacy checks in a single line of code.

Getting Started

Start in seconds

No wrapper object is required. Import DrishtiPy and access profiling directly through df.profile.

quickstart.py 
import pandas as pd
import drishtipy

df = pd.read_csv("data.csv")

# Understand the dataset
df.profile.info()

# Schema
df.profile.schema()

# Statistics
df.profile.statistics()

# Data quality
df.profile.quality()

# Quality score
df.profile.quality_score()

# ML readiness
df.profile.ml()

# ETL readiness
df.profile.etl()

# PII detection
df.profile.pii()

# Correlations
df.profile.correlations(by="pairs")

# HTML report
df.profile.html("report.html")

Reporting

Shareable HTML Reports

Convert your analysis into a standalone HTML report that can be opened in any modern browser.

reports.py 
# Complete profiling report

df.profile.html(
    "profile_report.html"
)


# Before / after comparison

df.profile.compare_html(
    df2,
    path="comparison_report.html"
)


# Relationship dashboard

result = df.profile.relationships()

result.to_html(
    "relationships.html"
)
Advanced Analysis

Relationship Discovery

DrishtiPy automatically analyzes meaningful relationships between column pairs using semantic types and appropriate statistical methods.

↔

Numeric ↔ Numeric

Pearson and Spearman methods identify linear and monotonic relationships.

η

Categorical ↔ Numeric

ANOVA effect size and optional significance testing.

V

Categorical ↔ Categorical

Cramér's V and normalized mutual information.

ƒ

Functional Dependencies

Identify potential relationships such as farmer_id → farmer_name.

Scalability

Large CSV Profiling

Large CSV files can be profiled using chunked reading and sampling instead of loading the entire source into memory.

large_data.py 
from drishtipy import DataProfiler

profiler = DataProfiler.from_csv(
    "huge_dataset.csv",
    sample_size=100_000,
    chunksize=50_000,
    random_state=42
)

profiler.info_dataframe()

# Check whether sampling was used
profiler.is_sampled

# Exact source row count
profiler.total_rows_in_source
Privacy

PII & Sensitive Data

DrishtiPy provides local analytical checks that help identify potentially personally identifiable information in datasets.

Email

Detect email address patterns.

Phone

Identify Aadhaar-shaped 12-digit patterns.

Possible PAN

Detect Indian PAN-like patterns.

IP Address

Name / Address

Philosophy

Built for pandas users

pandas-first

Extends pandas rather than replacing the workflow you already know.

Lightweight

Core package keeps dependencies intentionally minimal.

Non-destructive

Profiling operations analyze the DataFrame without modifying it.

Composable

Results remain pandas-friendly and can be filtered, sorted and exported.

Human-readable

Reports and summaries focus on actionable data problems.

Local Processing

Your DataFrame stays on the machine where DrishtiPy is running.
